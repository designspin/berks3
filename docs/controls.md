# Controls

## macOS Keyboard

The default keyboard controls are:

| Action | Key |
|--------|-----|
| Move Left | Z |
| Move Right | X |
| Move Up | F |
| Move Down | C |
| Fire | G |

### Customising Controls

You can redefine the keyboard controls from the title screen. Your custom bindings are saved automatically.

## Game Controller

Berks 3 supports game controllers on both macOS and iOS:

- **D-Pad / Left Stick** - Move
- **A Button** - Fire

## iOS Touch Controls

On iOS devices, use the on-screen joystick and fire button.
